📊 Sales Performance Dashboard

📌 Overview
This project is an interactive **Sales Performance Dashboard** built using **Power BI and Excel**.  
It provides insights into sales, profit, and category-wise performance to help understand business trends and decision-making.

---

🎯 Objective
The goal of this dashboard is to:
- Analyze overall sales and profit performance
- Identify top-performing categories and sub-categories
- Understand sales trends over time
- Provide a clear business overview through visual analytics

---

🛠️ Tools Used
- Microsoft Excel (Data Cleaning & Preparation)
- Power BI (Data Visualization & Dashboard Creation)

---

📂 Dataset
The dataset includes sales transaction data such as:
- Order Date  
- Region  
- Category & Sub-Category  
- Sales  
- Profit  

---

📊 Dashboard Features
- Interactive KPIs (Total Sales, Profit, Margin)
- Sales distribution by category (Donut Chart)
- Sales trend over time (Line Chart)
- Sub-category performance analysis (Bar/Table)
- Interactive filters for better exploration

---

📈 Key Insights
- Technology category contributes the highest share of sales  
- Sales show noticeable trends across time periods  
- Certain sub-categories outperform others significantly  
- Profitability varies across different product categories
